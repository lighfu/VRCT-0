<h3>
VRCT-0 是一個支援 VRChat 對話翻譯和紀錄的軟體。
</h3>

![](/docs/img/main_window.png)

<div align="left">

> [!IMPORTANT]
> VRCT-0 是以 [VRCT](https://github.com/misyaguziya/VRCT) 為基礎的**非官方衍生版**，與原版 VRCT 的開發團隊分開開發。
> VRCT-0 的問題與建議請回報至 [VRCT-0 的 Issues](https://github.com/lighfu/VRCT-0/issues)。請不要向原版 VRCT 的開發團隊詢問。

# 下載 & 安裝
請從 [GitHub 發布頁面](https://github.com/lighfu/VRCT-0/releases/) 下載 `VRCT-0-win-Setup.exe` 並執行。
它會以與原版 VRCT 不同的應用程式安裝，因此可以同時使用。

# 什麼是 VRCT-0？
VRCT-0 是一種透過提供聊天或語音翻譯來幫助語言不通的人對話的軟體。
這些功能專為在 VRChat 中使用而設計，但你也可以拿來看電影。

VRCT-0 可以：
- 💬 **傳送訊息至遊戲內 Chatbox**
- 🌐 **自動翻譯**
- 🎙 **麥克風轉文字**
- 🔈 **喇叭轉文字**

# 文件
大部分的畫面與操作與原版 VRCT 相同，因此原版 VRCT 的文件與介紹影片也可以參考。
VRCT-0 的問題請回報至上方的 Issues，而不是原版 VRCT。
